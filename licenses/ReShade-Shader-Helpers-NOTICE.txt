This header provides compatibility declarations. It is not a depth provider:
depth-dependent effects still require a valid supplied depth texture.

ReShadeUI.fxh in this package is a DXL-authored compatibility macro header under
AGPL-3.0-or-later. It is not the upstream file. The upstream shader used by our
GPU fixtures is downloaded unmodified to an external test directory.
